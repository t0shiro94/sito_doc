SITO VETRINA - DOTT.SSA ANNA ALBERICO

Questa cartella contiene la working copy del sito statico multipagina.

Struttura principale:
- index.html
- profilo.html
- aree-di-supporto.html
- contatti.html
- privacy.html
- 404.html
- assets/styles.css
- assets/site.js
- assets/images/
- assets/video/
- images/
- favicon.svg
- robots.txt
- sitemap.xml

Uso locale:
1. Apri index.html con doppio click.
2. Naviga con il menu principale.
3. Se sposti il sito, mantieni tutta la cartella completa.

Note progetto:
- Il sito e pensato come portfolio personale e base pronta per una futura pubblicazione online.
- I contenuti visibili sono stati rifiniti in chiave professionale e in prima persona.
- Le URL pubbliche previste su Netlify sono: /, /profilo/, /aree-di-supporto/, /contatti/ e /privacy/.
- Il file _redirects contiene solo redirect legacy da .html verso le URL canoniche; la normalizzazione con slash finale e demandata alle Pretty URLs di Netlify.
